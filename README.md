# Luxury Venue Website

A static React + Vite venue website prepared for GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files are generated in `dist/`.

## Deploy

Push this repository to GitHub, enable **Settings → Pages → GitHub Actions**, and push to the `main` branch. The included workflow builds and deploys the site automatically.

## Customize

Edit `src/App.tsx` and update the `venueConfig` values near the top of the file:

- Venue name
- Phone number
- Address
- Google Maps URL
- Email
- WhatsApp number
